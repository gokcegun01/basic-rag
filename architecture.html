1. FRONTEND: Web kullanıcı arayüzü. PDF yükleme, soru-cevap, typing indicator ve sohbet geçmişi.
2. BACKEND: FastAPI sunucusu. API endpoint'leri (`/ask`, `/upload`, `/files`) ve boru hattı yönetimi.
3. PII GUARDRAIL: T.C. Kimlik, Kart verisi ve Prompt Injection saldırı filtreleme mekanizması.
4. AUTONOMOUS LTM: Kullanıcı mesajından kalıcı gerçekleri süzüp LTM veritabanına kaydeden yapı.
5. AGENT 1 (INTENT): Soru amacını analiz eder, ID yazım hatalarını düzeltir ve doğru akışa yönlendirir.
6. TOOL INTENT: Kupon indirimi, aktif kuponlar, profil ve dosya listeleme araçları akışı.
7. RAG INTENT: Yüklenen PDF/TXT dokümanları içerisinde semantik vektör arama akışı.
8. WEB INTENT: İnternet üzerinden canlı bilgi getiren DuckDuckGo arama akışı.
9. PARAMETRIC: Doküman veya araç gerektirmeyen genel sohbet ve mantık akışı.
10. AGENT 2 (EXECUTOR): İlgili aracı, RAG vektör aramasını veya web aramasını çalıştırıp taslak yanıt üretir.
11. AGENT 3 (VERIFIER): Üretilen taslağı LTM ve bağlam ile karşılaştırarak doğrular ve Güven Skoru belirler.
12. AGENT 4 (INSPECTOR): Son kalite kontrolünü gerçekleştirir, hatalı reddetmeleri düzeltir ve JSON'u hazırlar.
13. YANIT ÇIKTISI: Yanıt, özet cümle, kaynak ve güven skorunun kullanıcı arayüzüne sunulması.
14. SİSTEM ARAÇLARI: Canlı veritabanı sorguları, kupon doğrulama ve Docling PDF indeksleme engine'i.
15. VERİ KATMANI: ChromaDB üzerinde saklanan `rag_documents` ve `user_long_term_memory` koleksiyonları.

⚙️ SİSTEMİN TEMEL ÖZELLİKLERİ

  • Docling Engine: PDF/TXT dosyalarını Markdown yapısına çevirip artımlı (incremental) indeksler.
  • 4-Ajanlı Boru Hattı: Intent Router ➔ Data Executor ➔ Grounding Verifier ➔ Output Inspector
  • Çift Katmanlı Güvenlik: PII Filtreleme (Regex) + System Prompt Injection Engelleme.
  • Gelişmiş Hafıza: ChromaDB Long-Term Memory (LTM) + Sliding Window Short-Term Memory (STM).
